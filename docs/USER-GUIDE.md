# Using EVA

## Conversations

Home has one starting point: enter a message or choose an example. Recent chats
reuse the navigation's chat list. **New chat** opens an empty conversation.

Search in the navigation matches titles and message content. The chat action
menu offers rename, pin, archive and delete. Archived conversations remain in
the expandable **Archived** section. Deletion requires confirmation and
permanently removes that conversation.

## Chat actions

The compact header shows the title and a background status when relevant.
Open **Conversation actions** for:

- **Create images**, using a compatible image endpoint on the selected provider.
- **Customize EVA for this chat**, for conversation-specific instructions.
- **Prompt library**, for reusable requests and templates.
- **Export conversation**, for export format and metadata controls.

Export and prompt-library controls open in dialogs. A document scope or custom
instructions appear in a small context row below the header.

## Answers and tools

Answers can contain errors. Follow file and web sources to verify facts.
Sources without an accessible target appear as text rather than links.
Review a write action's file, recipient or calendar before confirming it.

The send button becomes a stop control while a reply streams. Background work
can continue after leaving the chat. **Settings → Advanced → Background tasks**
lets you inspect those runs separately from the browser stream.

## Documents and data

Documents lists your indexed content. Search, filter or sort it, expand a row
to inspect extracted chunks and load further rows when needed. The index is
derived data; resetting it differs from deleting the original file.

Indexing continues on the server. Changing views does not stop it; use the
explicit stop action. Progress checks do not probe AI providers.

Core settings auto-save. Provider profiles use **Save & use provider**.
Blank key fields preserve an existing encrypted key. See
[Workspace settings](WORKSPACE.md) for retention, personal knowledge and exports.
